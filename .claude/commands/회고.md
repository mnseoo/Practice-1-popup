---

이번 세션 회고해줘. 캡처와 승격을 한 번에 처리.

[Step 1: 이번 세션 새 발견]
1. What(무엇을 강조할지, 어떤 톤이 맞는지)은 자동화 X
2. How(어떻게 강조할지, 어떤 토큰 쓸지)만 자동화 O
3. 1회성·가치 낮은 건 솔직하게 "X"로 분류

[Step 2: 기존 "🚧 진행 중 메모" 점검]
- 이번 세션에서 같은 패턴 또 나옴? → 2번째 발견 = 정식 승격 후보
- 새 발견이 기존 메모와 매치? → 같은 항목으로 묶기

[형식 분류]
- CLAUDE.md 핵심 스피릿: 항상 적용될 추상 원칙
- CLAUDE.md 룰: 메커니컬 규칙 (짝수, 1px 등)
- 새 스킬(skills/[이름]/SKILL.md): 절차 있는 반복 작업
- 슬래시 커맨드(.claude/commands/[이름].md): 자주 호출하는 단축 명령
- 진행 중 메모 (1번 발견): 임시 보관
- 자동화 X: 가치 없거나 시기상조

[출력 구조]

## 1. 정식 승격 (2번 이상 반복)
- 어디로 (스피릿/룰/스킬/커맨드)
- 문장 / 근거 (이번 + 이전 발견 지점)

## 2. 진행 중 메모 추가 (1번 발견)
- 문장 / 어디서

## 3. 자동화 후보 (스킬/커맨드)
- 형식 / 이름 / 1줄 설명
- 반복 근거 (구체적으로)
- 추천 초안

## 4. 우선순위
- 지금 당장 만들 것: 1~2개
- 만들지 말 것: 시기상조/가짜 패턴

각 카테고리 5개 이내. 억지로 채우지 말 것.
